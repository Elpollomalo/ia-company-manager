# Instrucciones para cualquier sesión nueva de Claude Code en este repo

Antes de hacer cualquier cosa, lee `vault/estado-proyectos/_mis-pendientes.md` y
`vault/estado-proyectos/_como-usar-esto.md` — ahí está el estado real de todos los proyectos
(qué se hizo, qué falta que decida Carlos, qué sigue). No asumas nada del estado de un proyecto
sin haber leído primero el archivo correspondiente en `vault/estado-proyectos/`.

También lee `house-rules.md` completo — sus reglas tienen prioridad absoluta.
